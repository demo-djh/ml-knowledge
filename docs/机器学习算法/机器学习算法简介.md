# 机器学习算法简介

> 本章分类讲解回归、分类、聚类等主流机器学习算法的核心原理、适用场景、优缺点，不堆砌复杂公式，以通俗语言讲透算法逻辑，帮助学习者精准匹配业务场景。

## 一、算法分类总览

机器学习算法按学习方式可分为三大类：

```
机器学习算法
├── 监督学习（有标签）
│   ├── 回归算法（预测连续值）
│   │   ├── 线性回归
│   │   ├── 岭回归 / Lasso
│   │   ├── 决策树回归
│   │   ├── 随机森林回归
│   │   └── XGBoost / LightGBM 回归
│   └── 分类算法（预测离散类别）
│       ├── 逻辑回归
│       ├── K近邻 (KNN)
│       ├── 决策树
│       ├── 随机森林
│       ├── 支持向量机 (SVM)
│       ├── 朴素贝叶斯
│       └── XGBoost / LightGBM 分类
├── 无监督学习（无标签）
│   ├── 聚类算法
│   │   ├── K-Means
│   │   ├── DBSCAN
│   │   └── 层次聚类
│   └── 降维算法
│       ├── PCA（主成分分析）
│       └── t-SNE
└── 集成学习（组合多个模型）
    ├── Bagging（随机森林）
    ├── Boosting（XGBoost、LightGBM、AdaBoost）
    └── Stacking
```

## 二、回归算法

回归算法用于预测**连续数值**，如房价、销量、温度等。

### 2.1 线性回归（Linear Regression）

**核心思想**：用一条直线（或超平面）拟合数据，使得预测值与真实值的误差平方和最小。

$$y = w_1x_1 + w_2x_2 + ... + w_nx_n + b$$

**通俗理解**：找到一条最能代表数据趋势的直线，新数据代入直线方程就能得到预测值。

| 优点 | 缺点 |
|------|------|
| 简单、快速、可解释性强 | 只能拟合线性关系 |
| 是很多高级模型的基础 | 对异常值敏感 |
| 训练和预测速度快 | 容易欠拟合复杂数据 |

**适用场景**：数据关系近似线性、需要可解释性、作为基线模型。

```python
from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(X_train, y_train)
print(model.coef_)   # 各特征的权重
print(model.intercept_)  # 截距
```

### 2.2 岭回归（Ridge）与 Lasso

在线性回归基础上加入正则化，防止过拟合。详见[数据正则化](../数据处理/数据正则化.md)章节。

- **Ridge（L2正则化）**：将权重压缩到较小值，最常用
- **Lasso（L1正则化）**：将不重要特征的权重压缩为0，自动特征选择

### 2.3 决策树回归（Decision Tree Regressor）

**核心思想**：通过一系列"是/否"问题将数据不断划分，每个叶子节点给出一个预测值。

**通俗理解**：像玩"20个问题"游戏，通过不断提问（特征是否大于某个值）缩小范围，最终给出预测。

| 优点 | 缺点 |
|------|------|
| 可解释性极强（可画成树状图） | 容易过拟合 |
| 不需要特征缩放 | 不稳定，数据小变化可能导致树结构大变 |
| 能处理非线性关系 | 预测精度一般不如集成模型 |

**适用场景**：需要可解释性、数据关系非线性、作为集成模型的基学习器。

### 2.4 随机森林回归（Random Forest Regressor）

**核心思想**：训练多棵决策树，每棵树看不同的数据子集和特征子集，最终取所有树预测的平均值。

**通俗理解**："三个臭皮匠顶个诸葛亮"，让很多棵有差异的树分别预测，取平均减少单棵树的过拟合。

| 优点 | 缺点 |
|------|------|
| 效果好，不易过拟合 | 模型体积大，预测相对慢 |
| 不需要太多调参 | 可解释性比单棵决策树差 |
| 能处理非线性和特征交互 | 对极端值可能预测不准 |

**适用场景**：表格数据、追求效果和稳定性、不想花太多时间调参。

### 2.5 XGBoost / LightGBM 回归

**核心思想**：Boosting 集成，逐棵训练决策树，每棵新树重点学习前面树预测错的样本。

**通俗理解**：像考试复习，第一遍学完后，重点复习做错的题，第二遍再重点复习还错的题，反复迭代提升。

| 优点 | 缺点 |
|------|------|
| 表格数据竞赛"大杀器"，效果极强 | 调参较复杂 |
| 训练速度快（LightGBM尤甚） | 可能过拟合，需要正则化 |
| 支持缺失值、类别特征 | 可解释性较差 |

**适用场景**：结构化表格数据、追求最高精度、Kaggle竞赛。

> 经验：在表格数据上，XGBoost/LightGBM 通常是效果最好的模型之一，几乎是"默认首选"。

## 三、分类算法

分类算法用于预测**离散类别**，如垃圾邮件/正常邮件、患病/健康、猫/狗等。

### 3.1 逻辑回归（Logistic Regression）

**核心思想**：虽然叫"回归"，但实际是分类算法。用 Sigmoid 函数将线性组合的结果映射到 [0,1] 区间，作为概率。

$$P(y=1) = \frac{1}{1 + e^{-(wx+b)}}$$

**通俗理解**：先算一个分数，再通过 S 形曲线把分数转成"属于正类的概率"，概率大于0.5就判为正类。

| 优点 | 缺点 |
|------|------|
| 简单、快速、可解释性强 | 只能处理线性可分问题 |
| 输出概率，可调整分类阈值 | 对异常值和多重共线性敏感 |
| 广泛用于工业界（如风控） | 特征工程要求高 |

**适用场景**：二分类问题、需要概率输出、需要可解释性（如信贷风控、医疗诊断）。

```python
from sklearn.linear_model import LogisticRegression
model = LogisticRegression(max_iter=1000)
model.fit(X_train, y_train)
y_pred_proba = model.predict_proba(X_test)  # 输出概率
```

### 3.2 K近邻（KNN, K-Nearest Neighbors）

**核心思想**：一个样本的类别由它周围最近的 K 个邻居的类别投票决定。

**通俗理解**："近朱者赤，近墨者黑"，看一个新样本周围最近的 K 个已知样本是什么类别，多数票决定它的类别。

| 优点 | 缺点 |
|------|------|
| 思想简单直观 | 预测慢（要计算与所有样本的距离） |
| 不需要训练过程 | 对高维数据效果差（维度灾难） |
| 能处理多分类 | 对特征尺度敏感，必须标准化 |
| 适合小数据集 | 不适合大数据集 |

**适用场景**：小数据集、低维数据、简单分类任务、作为基线对比。

> KNN 的 K 值是关键超参数：K太小容易受噪声影响，K太大可能欠拟合。常用交叉验证选择。

### 3.3 决策树分类（Decision Tree Classifier）

与决策树回归原理相同，只是叶子节点输出类别而非数值。通过信息增益或基尼不纯度选择最优划分。

**通俗理解**：像一个"决策流程图"，从根节点开始，根据特征值回答"是/否"，走到叶子节点得到分类结果。

| 优点 | 缺点 |
|------|------|
| 可解释性极强，可可视化 | 容易过拟合 |
| 不需要特征缩放 | 不稳定性高 |
| 能处理数值和类别特征 | 预测精度有限 |

### 3.4 随机森林分类（Random Forest Classifier）

与随机森林回归原理相同，多棵决策树投票决定类别。

| 优点 | 缺点 |
|------|------|
| 效果好，鲁棒性强 | 可解释性较差 |
| 不易过拟合 | 预测速度比单棵树慢 |
| 能评估特征重要性 | 模型文件较大 |

**特征重要性**：随机森林可以输出每个特征对预测的贡献程度，是特征选择的好工具。

```python
model = RandomForestClassifier()
model.fit(X_train, y_train)
importances = pd.Series(model.feature_importances_, index=X.columns)
importances.sort_values().plot.barh()  # 可视化特征重要性
```

### 3.5 支持向量机（SVM, Support Vector Machine）

**核心思想**：找到一个最优分类超平面，使得不同类别之间的间隔（Margin）最大。

**通俗理解**：在两类数据之间画一条"最宽的隔离带"，新样本落在隔离带哪一侧就属于哪一类。"最宽"意味着对噪声最不敏感。

**核技巧（Kernel Trick）**：当数据线性不可分时，将数据映射到更高维空间，使其变得可分。常用核函数：
- **线性核**：数据线性可分时使用
- **RBF核（高斯核）**：最常用，处理非线性关系
- **多项式核**：处理多项式关系

| 优点 | 缺点 |
|------|------|
| 小样本高维效果好 | 训练慢（大数据集不适合） |
| 核函数灵活，能处理非线性 | 对参数和核函数选择敏感 |
| 理论基础扎实 | 可解释性差 |
| 泛化能力强 | 预测速度一般 |

**适用场景**：小到中等规模数据集、高维数据（如文本分类）、非线性分类。

### 3.6 朴素贝叶斯（Naive Bayes）

**核心思想**：基于贝叶斯定理，假设特征之间相互独立（"朴素"的由来），计算每个类别的后验概率。

**通俗理解**：根据已有统计知识，计算"在这些特征出现的情况下，属于各类别的概率"，选概率最大的。

| 优点 | 缺点 |
|------|------|
| 极快，适合高维稀疏数据 | 特征独立假设在现实中常不成立 |
| 小样本也能工作 | 对输入数据的分布有假设 |
| 文本分类经典算法 | 概率输出不够准确 |

**适用场景**：文本分类（垃圾邮件、情感分析）、高维稀疏数据、需要快速训练的场景。

### 3.7 XGBoost / LightGBM 分类

与回归版本原理相同，输出类别概率。表格分类任务的"王者"。

## 四、聚类算法

聚类算法用于**无标签**数据，自动发现数据中的分组结构。

### 4.1 K-Means

**核心思想**：指定聚类数 K，随机选 K 个中心点，迭代执行"分配样本到最近中心"和"更新中心为簇内均值"，直到收敛。

**通俗理解**：
1. 随机选 K 个"组长"
2. 每个人加入离自己最近的组长的队伍
3. 每个队伍重新选中心（所有人的平均位置）作为新组长
4. 重复2-3，直到组长不再大变

| 优点 | 缺点 |
|------|------|
| 简单、快速、可扩展 | 需预先指定K值 |
| 适合大规模数据 | 对初始中心点敏感 |
| 结果易解释 | 只能发现球形簇，对非球形数据差 |
| 收敛有理论保证 | 对异常值敏感 |

**适用场景**：客户分群、图像压缩、数据预处理、已知大致类别数。

```python
from sklearn.cluster import KMeans

kmeans = KMeans(n_clusters=3, random_state=42)
labels = kmeans.fit_predict(X)
```

**选择K值——肘部法则：**

```python
inertias = []
for k in range(1, 11):
    km = KMeans(n_clusters=k, random_state=42)
    km.fit(X)
    inertias.append(km.inertia_)

plt.plot(range(1, 11), inertias, marker="o")
plt.xlabel("K值")
plt.ylabel("簇内误差平方和")
plt.title("肘部法则选K")
plt.show()
# 拐点处的K值通常是较优选择
```

### 4.2 DBSCAN

**核心思想**：基于密度的聚类，将足够密集的区域划分为一个簇，能发现任意形状的簇，并识别噪声点。

**通俗理解**：从一个点出发，如果它周围一定半径内有足够多的邻居，就形成一个簇，然后向外扩展；周围点少的点被视为噪声。

| 优点 | 缺点 |
|------|------|
| 不需要指定簇数量 | 需要调 eps 和 min_samples |
| 能发现任意形状的簇 | 高维数据效果下降 |
| 能自动识别噪声点 | 密度差异大时效果不好 |
| 对初始点不敏感 | 计算复杂度较高 |

**适用场景**：异常检测、空间数据聚类、簇形状不规则、需要识别离群点。

### 4.3 层次聚类（Hierarchical Clustering）

**核心思想**：自底向上（凝聚式）或自顶向下（分裂式）构建聚类层次树（树状图）。

**通俗理解**：凝聚式就是一开始每个点自己一个簇，然后每次把最近的两个簇合并，直到所有点在一个簇中，形成一棵"家族树"。

| 优点 | 缺点 |
|------|------|
| 不需要预先指定簇数 | 计算复杂度高（不适合大数据） |
| 可通过树状图直观展示 | 一旦合并不可撤销 |
| 结果层次结构有意义 | 对异常值敏感 |

**适用场景**：小数据集、需要层次结构、基因表达分析等。

## 五、降维算法

### 5.1 PCA（主成分分析）

**核心思想**：找到数据中方差最大的方向（主成分），将高维数据投影到低维空间，尽可能保留信息。

**通俗理解**：从多个相关特征中提炼出少数几个"综合指标"，每个综合指标是原特征的线性组合，且互不相关。

| 优点 | 缺点 |
|------|------|
| 快速、可扩展 | 主成分的可解释性较差 |
| 去除特征间的相关性 | 是线性方法，不能捕捉非线性关系 |
| 有助于可视化（降到2D/3D） | 对特征尺度敏感，需先标准化 |
| 减少计算量和过拟合风险 | 可能丢失重要信息 |

**适用场景**：数据降维、特征去相关、数据可视化、加速模型训练。

```python
from sklearn.decomposition import PCA

pca = PCA(n_components=2)  # 降到2维
X_pca = pca.fit_transform(X_scaled)
print(f"解释方差比例：{pca.explained_variance_ratio_}")
```

### 5.2 t-SNE

**核心思想**：非线性降维，特别适合高维数据的可视化，保持局部结构。

**适用场景**：高维数据可视化（如词向量、图像特征），不适合作为模型训练前的预处理（计算慢、不可扩展）。

## 六、集成学习

集成学习的核心思想是"**集体智慧**"——组合多个弱模型得到一个强模型。

### 6.1 Bagging（Bootstrap Aggregating）

**核心思想**：有放回地采样得到多个数据子集，每个子集训练一个模型，最终投票/平均。

**代表**：随机森林（Bagging + 决策树 + 随机特征选择）

**特点**：各模型独立并行训练，主要降低方差（减少过拟合）。

### 6.2 Boosting

**核心思想**：串行训练模型，每个新模型重点学习前面模型的错误。

**代表**：AdaBoost、XGBoost、LightGBM、CatBoost

**特点**：模型串行训练，主要降低偏差（提升拟合能力）。

### 6.3 Stacking

**核心思想**：用多个基模型的预测作为新特征，训练一个元模型做最终预测。

**特点**：效果可能更好，但复杂度高，容易过拟合，竞赛中常用。

## 七、算法选择决策树

面对一个新问题，如何选择算法？

```
开始
 │
 ├─ 有标签数据？
 │   ├─ 是 → 监督学习
 │   │   ├─ 预测连续值？→ 回归
 │   │   │   ├─ 线性关系？→ 线性回归/岭回归
 │   │   │   └─ 非线性/表格数据？→ 随机森林/XGBoost/LightGBM
 │   │   └─ 预测类别？→ 分类
 │   │       ├─ 需要可解释性？→ 逻辑回归/决策树
 │   │       ├─ 文本/高维稀疏？→ 朴素贝叶斯/线性SVM
 │   │       ├─ 小样本？→ SVM(RBF核)
 │   │       └─ 表格数据追求效果？→ 随机森林/XGBoost/LightGBM
 │   └─ 否 → 无监督学习
 │       ├─ 想分组？→ 聚类
 │       │   ├─ 已知簇数/球形簇？→ K-Means
 │       │   └─ 未知簇数/找异常？→ DBSCAN
 │       └─ 想降维/可视化？→ PCA / t-SNE
```

| PCA | 降维 | 快 | 弱 | - | 是 |
