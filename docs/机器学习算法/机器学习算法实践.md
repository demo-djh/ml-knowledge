## 七、实践六：Pipeline 流水线

实际项目中，数据预处理和模型训练应该封装成 Pipeline，避免数据泄露，也方便部署。

```python
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer

# 定义数值特征和分类特征的处理流程
numeric_features = ["年收入", "年龄"]
categorical_features = ["城市", "性别"]

numeric_transformer = Pipeline(steps=[
    ("imputer", SimpleImputer(strategy="median")),
    ("scaler", StandardScaler())
])

# 完整 Pipeline
preprocessor = ColumnTransformer(transformers=[
    ("num", numeric_transformer, numeric_features)
])

full_pipeline = Pipeline(steps=[
    ("preprocessor", preprocessor),
    ("classifier", RandomForestClassifier(random_state=RANDOM_STATE))
])

# 训练（自动完成预处理+建模）
full_pipeline.fit(X_train, y_train)

# 预测
y_pred = full_pipeline.predict(X_test)

# 保存完整 Pipeline
joblib.dump(full_pipeline, "full_pipeline.pkl")
```

> 使用 Pipeline 的好处：① 避免数据泄露（预处理只在训练集 fit）；② 代码简洁，部署方便；③ 可以对整个 Pipeline 做网格搜索调参。

## 九、常见问题

**Q：为什么我的模型训练精度很高但测试精度低？**
A：典型的过拟合。尝试：增加数据、降低模型复杂度、增加正则化、使用交叉验证、早停。

**Q：不同模型结果差异很大，怎么选？**
A：用交叉验证在同一训练集上评估多个模型，选择稳定且效果好的。不要只看单次测试集结果。

**Q：特征很多，怎么知道哪些有用？**
A：① 用随机森林的 feature_importances_；② 用 L1 正则化看哪些权重被压缩为0；③ 用 SelectKBest 做统计筛选；④ 递归特征消除（RFE）。

**Q：数据类别不平衡怎么办？**
A：① 过采样少数类（SMOTE）；② 欠采样多数类；③ 设置 class_weight="balanced"；④ 用 F1/AUC 而非 Accuracy 评估。

**Q：模型训练太慢怎么办？**
A：① 减少数据量（采样）；② 减少特征；③ 使用更快的模型（线性模型代替复杂模型）；④ 用 n_jobs=-1 利用多核；⑤ 增量学习。
