# Python 基础

Python 是机器学习的核心编程语言。本部分涵盖 Python 的安装配置与基础语法，为后续数据处理和算法实战打下编程基础。

## 章节列表

- [Python 安装入门](下载与环境配置README.md) — 从零下载安装 Python，配置 pip 镜像源
- [Python 基础语法](Python基础语法README.md) — 机器学习高频核心语法速通

## 学习目标

完成本部分学习后，你将能够：

1. 独立完成 Python 环境的安装与验证
2. 使用 pip 管理第三方库
3. 掌握变量、数据类型、列表、字典等核心语法
4. 编写简单的数据处理脚本
