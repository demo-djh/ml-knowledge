# 数据可视化

数据可视化是数据分析和机器学习中不可或缺的环节。通过图表，我们可以直观地发现数据规律、分布特征和异常情况，也能更清晰地展示模型结果。

## 章节列表

- [数据图表可视化](数据图表可视化.md) — Matplotlib 与 Seaborn 绘图实战

## 学习目标

完成本部分学习后，你将能够：

1. 使用 Matplotlib 绘制折线图、柱状图、散点图、饼图等基础图表
2. 使用 Seaborn 绘制统计图表（分布图、热力图、关系图等）
3. 针对不同数据类型和分析目的选择合适的图表
4. 美化图表，添加标题、标签、图例等元素
5. 将可视化融入机器学习的探索性分析和结果展示中
