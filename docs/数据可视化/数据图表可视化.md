# 数据图表可视化

> 本章讲解主流绘图工具的使用，掌握折线图、柱状图、散点图、热力图等常用图表的绘制方法，实现数据可视化分析，直观呈现数据规律、特征与分布特点。

## 一、可视化工具介绍

Python 生态中常用的可视化库：

| 库 | 特点 | 适用场景 |
|----|------|---------|
| **Matplotlib** | 最基础、最灵活，可精细控制每个元素 | 各种基础图表、论文配图 |
| **Seaborn** | 基于 Matplotlib，统计图表更美观简洁 | 统计分析、数据探索 |
| **Plotly** | 交互式图表，可缩放、悬停查看 | 报告、网页、探索性分析 |
| **Pandas 内置绘图** | 直接对 DataFrame 调用 plot | 快速查看数据 |

**新手建议**：先学 Matplotlib 基础，再学 Seaborn 提升效率和美观度。

## 三、Matplotlib 基础

### 3.1 图表基本结构

一个 Matplotlib 图表包含以下元素：

```
        ┌─────────────────────────────┐
        │         标题 (title)        │
        ├─────────────────────────────┤
        │  ┌───────────────────────┐  │
        │  │    y轴标签            │  │
        │  │    (ylabel)    ▲     │  │
        │  │                │     │  │
        │  │         绘图区域 │     │  │
        │  │         (Axes)  │     │  │
        │  │                └───► x轴标签(xlabel)
        │  └───────────────────────┘  │
        │         图例 (legend)        │
        └─────────────────────────────┘
```

### 3.2 基本绘图流程

```python
# 1. 创建画布和轴
fig, ax = plt.subplots(figsize=(8, 5))  # figsize 单位为英寸

# 2. 绘制图形
ax.plot([1, 2, 3, 4], [1, 4, 9, 16])

# 3. 设置属性
ax.set_title("我的第一张图", fontsize=14)
ax.set_xlabel("X轴")
ax.set_ylabel("Y轴")
ax.legend(["数据线"])

# 4. 显示/保存
plt.show()
# plt.savefig("chart.png", dpi=150, bbox_inches="tight")
```

### 3.3 折线图（Line Plot）

适合展示数据随时间或顺序的变化趋势。

```python
# 基础折线图
x = [1, 2, 3, 4, 5, 6, 7]
y = [23, 25, 28, 27, 30, 32, 31]

plt.figure(figsize=(8, 5))
plt.plot(x, y, marker="o", linestyle="-", color="steelblue", linewidth=2, label="温度")
plt.title("一周温度变化")
plt.xlabel("日期")
plt.ylabel("温度(°C)")
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()
```

**常用参数：**

| 参数 | 说明 | 可选值 |
|------|------|--------|
| `marker` | 数据点标记 | `"o"`圆圈, `"s"`方块, `"^"`三角, `"*"`星号 |
| `linestyle` | 线型 | `"-"`实线, `"--"`虚线, `":"`点线, `"-."`点划线 |
| `color` | 颜色 | 命名颜色、十六进制、RGB |
| `linewidth` | 线宽 | 数字 |
| `label` | 图例标签 | 字符串 |

**多条折线：**

```python
x = np.arange(1, 8)
y1 = [23, 25, 28, 27, 30, 32, 31]
y2 = [15, 16, 18, 17, 20, 22, 21]

plt.figure(figsize=(8, 5))
plt.plot(x, y1, marker="o", label="北京")
plt.plot(x, y2, marker="s", label="上海")
plt.title("北京 vs 上海 一周温度")
plt.xlabel("日期")
plt.ylabel("温度(°C)")
plt.legend()
plt.show()
```

### 3.4 柱状图（Bar Plot）

适合比较不同类别之间的数值大小。

```python
categories = ["产品A", "产品B", "产品C", "产品D"]
values = [350, 480, 290, 520]

plt.figure(figsize=(8, 5))
plt.bar(categories, values, color=["#4C72B0", "#55A868", "#C44E52", "#8172B3"])
plt.title("各产品销售额")
plt.xlabel("产品")
plt.ylabel("销售额(万元)")
plt.show()
```

**水平柱状图：**

```python
plt.barh(categories, values, color="steelblue")
plt.title("各产品销售额")
plt.xlabel("销售额(万元)")
plt.show()
```

**分组柱状图：**

```python
x = np.arange(len(categories))
width = 0.35
q1 = [350, 480, 290, 520]
q2 = [420, 510, 350, 490]

plt.figure(figsize=(8, 5))
plt.bar(x - width/2, q1, width, label="Q1")
plt.bar(x + width/2, q2, width, label="Q2")
plt.xticks(x, categories)
plt.title("各产品季度销售额对比")
plt.legend()
plt.show()
```

### 3.5 散点图（Scatter Plot）

适合展示两个变量之间的关系和相关性。

```python
np.random.seed(42)
x = np.random.randn(100)
y = 2 * x + np.random.randn(100) * 0.5
sizes = np.random.randint(20, 200, 100)

plt.figure(figsize=(8, 5))
plt.scatter(x, y, c="steelblue", alpha=0.6, s=sizes, edgecolors="white")
plt.title("变量 X 与 Y 的关系")
plt.xlabel("X")
plt.ylabel("Y")
plt.grid(True, alpha=0.3)
plt.show()
```

**用颜色表示第三维：**

```python
plt.scatter(x, y, c=y, cmap="viridis", alpha=0.7)
plt.colorbar(label="Y值")  # 显示颜色条
plt.show()
```

### 3.6 饼图（Pie Chart）

适合展示各部分占总体的比例。

```python
labels = ["产品A", "产品B", "产品C", "产品D"]
sizes = [30, 40, 20, 10]
colors = ["#4C72B0", "#55A868", "#C44E52", "#8172B3"]
explode = (0, 0.1, 0, 0)  # 突出显示第二块

plt.figure(figsize=(7, 7))
plt.pie(sizes, explode=explode, labels=labels, colors=colors,
        autopct="%1.1f%%", shadow=True, startangle=90)
plt.title("产品销售占比")
plt.axis("equal")  # 保证饼图为正圆形
plt.show()
```

> 饼图类别不宜过多（建议不超过 6 个），否则难以阅读。类别多时用柱状图更好。

### 3.7 直方图（Histogram）

适合展示数值数据的分布情况。

```python
data = np.random.randn(1000)  # 正态分布随机数

plt.figure(figsize=(8, 5))
plt.hist(data, bins=30, color="steelblue", edgecolor="white", alpha=0.8)
plt.title("数据分布直方图")
plt.xlabel("数值")
plt.ylabel("频数")
plt.show()
```

**bins 参数**：控制柱子数量，越大越精细，越小越平滑。

### 3.8 箱线图（Box Plot）

适合展示数据的分布、中位数和异常值。

```python
data = [np.random.randn(100) * 10 + 50,
        np.random.randn(100) * 15 + 45,
        np.random.randn(100) * 8 + 55]

plt.figure(figsize=(8, 5))
plt.boxplot(data, labels=["A组", "B组", "C组"], patch_artist=True)
plt.title("三组数据分布对比")
plt.ylabel("数值")
plt.show()
```

箱线图各部分含义：
- **箱体**：下四分位数(Q1)到上四分位数(Q3)，中间50%的数据
- **中线**：中位数
- **须线**：延伸到 1.5×IQR 范围内的最远数据点
- **离群点**：须线之外的点（可能是异常值）

### 3.9 子图（Subplots）

在一个画布中排列多个图表：

```python
fig, axes = plt.subplots(2, 2, figsize=(12, 10))

# 第1个子图：折线图
axes[0, 0].plot([1,2,3,4], [1,4,9,16])
axes[0, 0].set_title("折线图")

# 第2个子图：柱状图
axes[0, 1].bar(["A","B","C"], [3,5,2])
axes[0, 1].set_title("柱状图")

# 第3个子图：散点图
axes[1, 0].scatter(np.random.randn(50), np.random.randn(50))
axes[1, 0].set_title("散点图")

# 第4个子图：直方图
axes[1, 1].hist(np.random.randn(200), bins=20)
axes[1, 1].set_title("直方图")

plt.tight_layout()  # 自动调整子图间距
plt.show()
```

## 四、Seaborn 统计图表

Seaborn 基于 Matplotlib，提供更高级的统计图表接口，默认样式更美观。

### 4.1 分布图

```python
# 直方图 + 核密度估计曲线
sns.histplot(data=df, x="成绩", kde=True, bins=20)
plt.title("成绩分布")
plt.show()

# 核密度估计图（KDE）
sns.kdeplot(data=df, x="成绩", fill=True)
plt.show()
```

### 4.2 分类图

```python
# 箱线图
sns.boxplot(data=df, x="城市", y="成绩")
plt.title("各城市成绩分布")
plt.show()

# 小提琴图（箱线图 + 密度图的结合）
sns.violinplot(data=df, x="城市", y="成绩")
plt.show()

# 条形图（带误差棒）
sns.barplot(data=df, x="城市", y="成绩", errorbar="sd")
plt.title("各城市平均成绩")
plt.show()
```

### 4.3 关系图

```python
# 散点图（可按类别着色）
sns.scatterplot(data=df, x="年龄", y="成绩", hue="城市", style="城市", s=100)
plt.title("年龄与成绩关系")
plt.show()

# 回归线散点图
sns.regplot(data=df, x="年龄", y="成绩")
plt.title("年龄与成绩（带回归线）")
plt.show()
```

### 4.4 热力图（Heatmap）

适合展示矩阵数据、相关性矩阵。

```python
# 计算相关性矩阵
corr = df[["年龄", "成绩", "收入", "经验"]].corr()

plt.figure(figsize=(8, 6))
sns.heatmap(corr, annot=True, fmt=".2f", cmap="coolwarm",
            center=0, square=True, linewidths=0.5)
plt.title("特征相关性热力图")
plt.show()
```

**参数说明：**
- `annot=True`：在格子中显示数值
- `fmt=".2f"`：数值格式（两位小数）
- `cmap="coolwarm"`：颜色映射
- `center=0`：以0为颜色中心（正负值颜色区分明显）

### 4.5 配对图（Pair Plot）

一次性展示所有数值特征两两之间的关系，适合数据探索。

```python
sns.pairplot(df[["年龄", "成绩", "收入", "城市"]], hue="城市", diag_kind="hist")
plt.suptitle("特征配对关系图", y=1.02)
plt.show()
```

> 特征较多时 pairplot 会很密集，建议选择 3~5 个关键特征。

## 五、图表选择指南

| 分析目的 | 推荐图表 |
|---------|---------|
| 展示趋势变化 | 折线图 |
| 比较类别大小 | 柱状图 / 条形图 |
| 展示占比关系 | 饼图 / 堆叠柱状图 |
| 展示两个变量关系 | 散点图 |
| 展示数据分布 | 直方图 / 箱线图 / 小提琴图 |
| 展示多变量关系 | 热力图 / 配对图 |
| 展示时间序列 | 折线图 |
| 展示排名 | 条形图（排序后） |

## 六、机器学习中的可视化应用

### 6.1 探索性数据分析（EDA）

```python
# 1. 查看目标变量分布
sns.histplot(data=df, x="目标列", kde=True)
plt.title("目标变量分布")
plt.show()

# 2. 特征与目标的关系
sns.boxplot(data=df, x="分类特征", y="目标列")

# 3. 特征间相关性
corr = df.corr()
sns.heatmap(corr, annot=True, cmap="coolwarm", center=0)
plt.show()
```

### 6.2 模型结果可视化

```python
# 实际值 vs 预测值散点图
plt.scatter(y_test, y_pred, alpha=0.6)
plt.plot([y_test.min(), y_test.max()], [y_test.min(), y_test.max()], "r--")
plt.xlabel("实际值")
plt.ylabel("预测值")
plt.title("实际值 vs 预测值")
plt.show()

# 残差图
residuals = y_test - y_pred
plt.scatter(y_pred, residuals, alpha=0.6)
plt.axhline(y=0, color="r", linestyle="--")
plt.xlabel("预测值")
plt.ylabel("残差")
plt.title("残差图")
plt.show()
```

## 七、图表美化技巧

```python
# 1. 设置全局风格
plt.style.use("seaborn-v0_8-whitegrid")  # 或 "ggplot", "fivethirtyeight"

# 2. 调整字体
plt.rcParams.update({
    "font.size": 12,
    "axes.titlesize": 14,
    "axes.labelsize": 12,
    "legend.fontsize": 10
})

# 3. 去除上右边框（seaborn 风格）
sns.despine()

# 4. 添加数据标签
bars = plt.bar(categories, values)
for bar in bars:
    height = bar.get_height()
    plt.text(bar.get_x() + bar.get_width()/2., height,
             f"{height}", ha="center", va="bottom")

# 5. 保存高清图
plt.savefig("chart.png", dpi=300, bbox_inches="tight", facecolor="white")
```

## 八、常见问题

**Q：图表中中文显示为方框？**
A：配置中文字体：`plt.rcParams["font.sans-serif"] = ["SimHei"]`，并确保系统已安装该字体。Linux 可安装 `fonts-wqy-zenhei`。

**Q：Jupyter 中图表不显示？**
A：在 Notebook 开头运行 `%matplotlib inline`。

**Q：如何保存高清图片？**
A：`plt.savefig("filename.png", dpi=300, bbox_inches="tight")`，dpi 越高越清晰。

**Q：图表元素重叠怎么办？**
A：使用 `plt.tight_layout()` 自动调整，或手动设置 `plt.subplots_adjust()`。

**Q：Seaborn 和 Matplotlib 可以混用吗？**
A：完全可以。Seaborn 底层就是 Matplotlib，用 Seaborn 画图后仍可用 Matplotlib 的 `plt.title()`、`plt.xlabel()` 等设置属性。
