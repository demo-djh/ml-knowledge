# 数据基础处理

> 本章针对原始数据杂乱、缺失、异常、重复等问题，讲解数据清洗、去重、补缺、筛选、转换等基础处理方法，掌握机器学习前置核心实操，保障数据质量。

## 一、为什么需要数据处理

原始数据（Raw Data）通常是"脏"的，存在各种问题：

- 数据缺失：某些字段为空
- 数据重复：同一条记录出现多次
- 数据异常：明显不合理的值（如年龄 200 岁）
- 格式不统一：日期格式混乱、大小写不一致
- 类型错误：数字被存为字符串

**垃圾进，垃圾出（Garbage In, Garbage Out）**：数据质量直接决定模型效果。数据处理通常占整个机器学习项目 60%~80% 的工作量。

## 三、处理缺失值

### 3.1 检测缺失值

```python
# 查看每列缺失值数量
df.isnull().sum()

# 查看缺失比例
df.isnull().mean() * 100

# 查看包含缺失值的行
df[df.isnull().any(axis=1)]
```

### 3.2 删除缺失值

```python
# 删除包含任何缺失值的行
df_clean = df.dropna()

# 删除全部为缺失值的行
df_clean = df.dropna(how="all")

# 删除指定列有缺失值的行
df_clean = df.dropna(subset=["成绩"])

# 删除缺失值超过阈值的列
df_clean = df.dropna(axis=1, thresh=len(df)*0.7)  # 保留非空值占70%以上的列
```

### 3.3 填充缺失值

```python
# 用固定值填充
df["成绩"] = df["成绩"].fillna(0)

# 用均值填充（数值列）
df["成绩"] = df["成绩"].fillna(df["成绩"].mean())

# 用中位数填充（受异常值影响小）
df["成绩"] = df["成绩"].fillna(df["成绩"].median())

# 用众数填充（分类列）
df["城市"] = df["城市"].fillna(df["城市"].mode()[0])

# 用前一个值填充（时间序列数据常用）
df["成绩"] = df["成绩"].fillna(method="ffill")

# 用后一个值填充
df["成绩"] = df["成绩"].fillna(method="bfill")

# 按分组填充（用同城市的平均成绩填充）
df["成绩"] = df.groupby("城市")["成绩"].transform(
    lambda x: x.fillna(x.mean())
)
```

**填充策略选择：**

| 场景 | 推荐方法 |
|------|---------|
| 缺失比例 < 5% | 删除或简单填充 |
| 数值列、分布近似正态 | 均值填充 |
| 数值列、有异常值 | 中位数填充 |
| 分类列 | 众数填充 |
| 时间序列 | 前向/后向填充 |
| 缺失比例 > 30% | 考虑删除该列，或用模型预测填充 |

## 五、处理异常值

### 5.1 检测异常值

**方法一：统计方法（IQR 法）**

```python
def detect_outliers_iqr(df, column):
    """使用四分位距(IQR)检测异常值"""
    Q1 = df[column].quantile(0.25)
    Q3 = df[column].quantile(0.75)
    IQR = Q3 - Q1
    lower = Q1 - 1.5 * IQR
    upper = Q3 + 1.5 * IQR
    outliers = df[(df[column] < lower) | (df[column] > upper)]
    return outliers, lower, upper

outliers, lower, upper = detect_outliers_iqr(df, "成绩")
print(f"正常范围：[{lower:.1f}, {upper:.1f}]")
print(f"异常值数量：{len(outliers)}")
```

**方法二：Z-score 法**

```python
from scipy import stats

z_scores = stats.zscore(df["成绩"].dropna())
outliers_mask = (z_scores.abs() > 3)  # |z| > 3 视为异常
```

**方法三：可视化（箱线图）**

```python
import matplotlib.pyplot as plt
plt.boxplot(df["成绩"].dropna())
plt.show()
```

### 5.2 处理异常值

```python
# 方法1：删除异常值
df_clean = df[(df["成绩"] >= lower) & (df["成绩"] <= upper)]

# 方法2：截断（将异常值替换为边界值）
df["成绩"] = df["成绩"].clip(lower=lower, upper=upper)

# 方法3：用中位数替换
median = df["成绩"].median()
df.loc[(df["成绩"] < lower) | (df["成绩"] > upper), "成绩"] = median
```

> 异常值不一定是错误，可能是真实存在的极端情况。处理前需结合业务判断，不要盲目删除。

## 九、完整数据清洗流程示例

```python
import pandas as pd

def clean_data(file_path):
    """完整的数据清洗流程"""
    # 1. 读取数据
    df = pd.read_csv(file_path, encoding="utf-8-sig")
    print(f"原始数据：{df.shape[0]} 行，{df.shape[1]} 列")

    # 2. 删除完全重复的行
    df = df.drop_duplicates()
    print(f"去重后：{len(df)} 行")

    # 3. 处理缺失值
    # 数值列用中位数填充
    numeric_cols = df.select_dtypes(include=[np.number]).columns
    for col in numeric_cols:
        df[col] = df[col].fillna(df[col].median())

    # 分类列用众数填充
    cat_cols = df.select_dtypes(include=["object"]).columns
    for col in cat_cols:
        df[col] = df[col].fillna(df[col].mode()[0])

    # 4. 处理异常值（用IQR法截断）
    for col in numeric_cols:
        Q1 = df[col].quantile(0.25)
        Q3 = df[col].quantile(0.75)
        IQR = Q3 - Q1
        df[col] = df[col].clip(Q1 - 1.5*IQR, Q3 + 1.5*IQR)

    # 5. 字符串标准化
    for col in cat_cols:
        df[col] = df[col].str.strip()

    # 6. 保存清洗后的数据
    df.to_csv("cleaned_data.csv", index=False, encoding="utf-8-sig")
    print(f"清洗完成，已保存。最终：{len(df)} 行，{df.shape[1]} 列")
    return df
```

## 十、常见问题

**Q：read_csv 读取中文乱码？**
A：尝试 `encoding="utf-8-sig"`、`encoding="gbk"` 或 `encoding="gb18030"`。

**Q：数据量太大内存不够怎么办？**
A：① 使用 `chunksize` 分块读取；② 用 `dtype` 指定更节省内存的类型；③ 删除不需要的列；④ 使用 Dask 或 Polars 等大数据处理库。

**Q：如何快速了解一份新数据？**
A：依次执行 `df.shape` → `df.head()` → `df.info()` → `df.describe()` → `df.isnull().sum()`，几分钟内即可掌握数据概况。

**Q：fillna 后数据没变？**
A：Pandas 操作默认不修改原数据，需要赋值回去：`df = df.fillna(...)` 或使用 `inplace=True` 参数（不推荐）。
