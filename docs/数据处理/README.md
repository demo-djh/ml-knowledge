# 数据处理

数据是机器学习的燃料。本部分覆盖从数据获取到数据清洗、再到数据正则化的完整流程，解决机器学习中"数据从哪来、数据怎么洗、数据怎么标准化"的核心问题。

## 章节列表

- [数据抓取（爬虫）](数据抓取.md) — 网络数据采集核心逻辑与实操方法
- [数据基础处理](数据基础处理.md) — 数据清洗、去重、补缺、筛选、转换
- [数据正则化](数据正则化.md) — 标准化、归一化与正则约束

## 学习目标

完成本部分学习后，你将能够：

1. 使用 requests + BeautifulSoup 抓取网页数据
2. 使用 Pandas 进行数据清洗和预处理
3. 处理缺失值、重复值、异常值
4. 掌握标准化、归一化等数据正则化方法
5. 为模型训练准备合格的输入数据
