# 数据抓取（爬虫）

> 本章讲解网络数据抓取的核心逻辑与实操方法，掌握主流爬虫工具的使用，实现结构化、非结构化数据的批量采集，解决机器学习**数据来源**的核心问题。

## 一、为什么需要爬虫

机器学习模型需要大量数据来训练。数据来源主要有三种：

1. **公开数据集**：如 Kaggle、UCI、国家统计局等（最推荐）
2. **API 接口**：一些平台提供数据 API（如天气、股票、社交媒体）
3. **网络爬虫**：从网页上自动提取数据（当没有现成数据集和 API 时）

> 合规提示：爬取数据时请遵守目标网站的 `robots.txt` 协议和相关法律法规，不要爬取个人隐私数据、不要对服务器造成过大压力、爬取的数据仅供学习研究使用。

## 二、爬虫基本原理

爬虫的工作流程很简单：

```
发送请求 → 获取网页内容 → 解析提取数据 → 保存数据
```

1. **发送请求**：模拟浏览器向目标网址发送 HTTP 请求
2. **获取响应**：服务器返回网页 HTML 内容
3. **解析数据**：从 HTML 中提取需要的信息
4. **存储数据**：保存为 CSV、JSON、数据库等格式

## 四、requests 库基础

### 4.1 发送 GET 请求

```python
import requests

# 发送 GET 请求
url = "https://example.com"
response = requests.get(url)

# 查看响应状态码
print(response.status_code)  # 200 表示成功

# 查看响应内容（文本形式）
print(response.text)

# 查看响应内容（字节形式，用于图片/文件）
print(response.content)
```

**常见状态码：**

| 状态码 | 含义 |
|--------|------|
| 200 | 请求成功 |
| 403 | 被拒绝访问（可能被反爬） |
| 404 | 页面不存在 |
| 500 | 服务器内部错误 |

### 4.2 带参数的请求

```python
# URL 参数
params = {
    "keyword": "机器学习",
    "page": 1
}
response = requests.get("https://example.com/search", params=params)
# 实际请求 URL：https://example.com/search?keyword=机器学习&page=1
```

### 4.3 设置请求头（伪装浏览器）

很多网站会检查 User-Agent 来判断是否为爬虫，设置请求头伪装成浏览器：

```python
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36",
    "Accept-Language": "zh-CN,zh;q=0.9"
}

response = requests.get(url, headers=headers)
```

### 4.4 超时与异常处理

```python
try:
    response = requests.get(url, headers=headers, timeout=10)
    response.raise_for_status()  # 状态码非200时抛出异常
except requests.exceptions.Timeout:
    print("请求超时")
except requests.exceptions.HTTPError as e:
    print(f"HTTP错误：{e}")
except requests.exceptions.RequestException as e:
    print(f"请求异常：{e}")
```

## 五、BeautifulSoup 解析 HTML

### 5.1 基本用法

```python
from bs4 import BeautifulSoup

html = """
<html>
<head><title>示例页面</title></head>
<body>
    <h1>欢迎学习爬虫</h1>
    <div class="content">
        <p class="intro">这是第一段</p>
        <p class="intro">这是第二段</p>
        <a href="https://example.com" id="link1">链接1</a>
    </div>
    <ul>
        <li>项目A</li>
        <li>项目B</li>
        <li>项目C</li>
    </ul>
</body>
</html>
"""

# 创建 BeautifulSoup 对象
soup = BeautifulSoup(html, "lxml")  # 或 "html.parser"
```

### 5.2 查找元素

```python
# find：查找第一个匹配的元素
title = soup.find("title")
print(title.text)  # 示例页面

# find_all：查找所有匹配的元素，返回列表
paragraphs = soup.find_all("p")
for p in paragraphs:
    print(p.text)

# 按 class 查找
intros = soup.find_all("p", class_="intro")

# 按 id 查找
link = soup.find("a", id="link1")

# 按属性查找
soup.find_all("a", href="https://example.com")

# CSS 选择器（更灵活）
soup.select("div.content p")        # div.content 下的所有 p
soup.select(".intro")               # class 为 intro 的元素
soup.select("#link1")               # id 为 link1 的元素
soup.select("ul li")                # ul 下的所有 li
```

### 5.3 提取数据

```python
# 获取标签文本
element.text          # 获取所有文本（含子标签）
element.get_text()    # 同上，可加参数控制

# 获取属性值
link = soup.find("a")
link["href"]               # 获取 href 属性
link.get("href")           # 同上，属性不存在时返回 None
link.get("class", [])      # 带默认值

# 获取标签名
link.name              # "a"
```

## 六、实战示例：抓取书籍信息

以下是一个完整的爬虫示例，抓取虚构书籍网站的书名、价格和评分：

```python
import requests
from bs4 import BeautifulSoup
import pandas as pd
import time

def scrape_books(base_url, pages=3):
    """抓取多页书籍数据"""
    books = []
    headers = {
        "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
    }

    for page in range(1, pages + 1):
        url = f"{base_url}?page={page}"
        print(f"正在抓取第 {page} 页：{url}")

        try:
            response = requests.get(url, headers=headers, timeout=10)
            response.raise_for_status()
        except Exception as e:
            print(f"抓取失败：{e}")
            continue

        soup = BeautifulSoup(response.text, "lxml")

        # 假设每本书在 <article class="book"> 中
        items = soup.find_all("article", class_="book")

        for item in items:
            book = {}
            # 书名
            title_tag = item.find("h3")
            book["书名"] = title_tag.text.strip() if title_tag else "未知"

            # 价格
            price_tag = item.find("span", class_="price")
            book["价格"] = price_tag.text.strip() if price_tag else "未知"

            # 评分
            rating_tag = item.find("span", class_="rating")
            book["评分"] = rating_tag.text.strip() if rating_tag else "未知"

            books.append(book)

        # 礼貌延时，避免给服务器太大压力
        time.sleep(1)

    return books

# 运行爬虫（示例 URL，实际使用时替换为真实目标）
# books_data = scrape_books("https://books.toscrape.com/catalogue/page-1.html", pages=3)
# df = pd.DataFrame(books_data)
# df.to_csv("books.csv", index=False, encoding="utf-8-sig")
# print(f"共抓取 {len(df)} 条数据，已保存到 books.csv")
```

> 上述代码中的 URL 为示例。推荐练习网站：[https://books.toscrape.com/](https://books.toscrape.com/)（专门用于爬虫练习的网站）

## 七、处理动态加载页面

有些网页的数据是通过 JavaScript 动态加载的，requests 只能获取初始 HTML，拿不到动态数据。

### 7.1 方法一：分析网络请求（推荐）

按 F12 打开开发者工具 → Network 标签 → 刷新页面 → 找到返回数据的 XHR/Fetch 请求 → 直接请求该 API：

```python
# 很多网站的数据通过 JSON API 加载，直接请求 API 更高效
api_url = "https://example.com/api/books?page=1"
response = requests.get(api_url, headers=headers)
data = response.json()  # 直接解析为 Python 字典/列表
```

### 7.2 方法二：使用 Selenium（万能但慢）

Selenium 可以驱动真实浏览器，能处理 JavaScript 动态渲染：

```bash
pip install selenium
```

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
import time

# 启动浏览器（需先下载对应浏览器驱动）
driver = webdriver.Chrome()  # 或 webdriver.Firefox()

# 打开页面
driver.get("https://example.com")

# 等待动态内容加载
time.sleep(3)

# 获取渲染后的页面内容
html = driver.page_source
soup = BeautifulSoup(html, "lxml")

# 也可以直接用 Selenium 查找元素
titles = driver.find_elements(By.CSS_SELECTOR, "h3.title")
for title in titles:
    print(title.text)

# 关闭浏览器
driver.quit()
```

> Selenium 启动慢、资源消耗大，仅在分析 API 无法解决时使用。

## 八、反爬与应对

| 反爬手段 | 应对方法 |
|---------|---------|
| 检查 User-Agent | 设置合理的请求头 |
| IP 频率限制 | 降低请求频率（time.sleep）、使用代理 IP |
| 需要登录 | 使用 requests.Session() 保持登录态，或携带 Cookie |
| 验证码 | 打码平台 / Selenium 手动处理（学习阶段建议避开） |
| 动态渲染 | 分析 API 或使用 Selenium |

**爬虫礼仪：**
- 设置合理的请求间隔（至少 1 秒）
- 遵守 robots.txt 协议
- 不要在网站高峰期大量爬取
- 仅爬取公开数据

## 十、常见问题

**Q：requests.get() 返回的内容是乱码？**
A：设置 `response.encoding = response.apparent_encoding` 自动检测编码，或手动设置为 `"utf-8"` / `"gbk"`。

**Q：BeautifulSoup 解析后找不到元素？**
A：① 确认元素是否在 HTML 中（可能是动态加载）；② 检查选择器是否正确；③ 换用 `lxml` 解析器。

**Q：爬取大量数据时被封 IP？**
A：增加延时、轮换 User-Agent、使用代理 IP 池，或分时段爬取。

**Q：有没有更简单的爬虫框架？**
A：进阶可学习 Scrapy 框架，适合大规模、结构化的爬虫项目。但入门阶段 requests + BeautifulSoup 已足够。
