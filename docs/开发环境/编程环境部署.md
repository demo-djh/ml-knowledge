# 编程环境部署

> 本章讲解机器学习开发中最常用的两款工具：**VS Code**（代码编辑器）和 **Jupyter Notebook**（交互式笔记本），帮助你搭建高效、舒适的开发环境。

## 一、开发工具选择

机器学习开发中，常用的编程环境有以下几种：

| 工具 | 类型 | 适用场景 | 推荐度 |
|------|------|---------|--------|
| **VS Code** | 代码编辑器 | 编写完整脚本、项目开发 | 新手首选 |
| **Jupyter Notebook** | 交互式笔记本 | 数据分析、实验探索、教学演示 | 必备工具 |
| **PyCharm** | 集成开发环境(IDE) | 大型项目、专业开发 | 进阶可选 |
| **Google Colab** | 在线笔记本 | 无需配置、免费GPU、快速实验 | 补充工具 |

**新手建议**：同时安装 VS Code 和 Jupyter Notebook。VS Code 用于写完整代码，Jupyter 用于边写边看结果的探索性分析。

## 二、VS Code 安装与配置

### 2.1 下载安装

1. 访问官网：[https://code.visualstudio.com/](https://code.visualstudio.com/)
2. 点击下载对应系统的安装包
3. 双击安装，一路下一步即可（Windows 安装时建议勾选"添加到 PATH"）

### 2.2 安装 Python 扩展

1. 打开 VS Code
2. 点击左侧边栏的扩展图标（或按 `Ctrl+Shift+X` / `Cmd+Shift+X`）
3. 搜索 `Python`，安装 Microsoft 官方发布的 Python 扩展
4. 搜索 `Pylance`，安装（提供更好的代码补全和类型检查）

**推荐安装的扩展：**

| 扩展名称 | 功能 |
|---------|------|
| Python | Python 语言支持、调试、运行 |
| Pylance | 智能代码补全、类型检查 |
| Jupyter | 在 VS Code 中运行 Notebook |
| Code Runner | 一键运行代码片段 |
| Material Icon Theme | 美观的文件图标 |
| Chinese (Simplified) | 中文语言包 |

### 2.3 配置 Python 解释器

1. 打开一个 `.py` 文件
2. 按 `Ctrl+Shift+P` / `Cmd+Shift+P` 打开命令面板
3. 输入 `Python: Select Interpreter`
4. 选择你安装的 Python 版本（或 Anaconda 环境）

### 2.4 运行 Python 代码

**方式一：右键运行**
- 在编辑器中右键 → "Run Python File in Terminal"

**方式二：使用 Code Runner**
- 安装 Code Runner 扩展后，点击右上角的播放按钮

**方式三：终端运行**
- 按 `` Ctrl+` `` 打开集成终端，输入 `python 文件名.py`

### 2.5 调试代码

1. 在代码行号左侧点击，设置断点（红点）
2. 按 `F5` 启动调试
3. 使用调试工具栏：继续(F5)、单步跳过(F10)、单步跳入(F11)、停止(Shift+F5)
4. 左侧"变量"面板可查看当前所有变量的值

## 三、Jupyter Notebook 安装与使用

### 3.1 什么是 Jupyter Notebook

Jupyter Notebook 是一个**交互式**的编程环境，可以在一个文档中混合编写代码、文本说明、公式和图表。每段代码可以独立运行，结果直接显示在代码下方，非常适合数据分析和机器学习实验。

**核心概念：**
- **Cell（单元格）**：文档的基本单元，分为代码单元和 Markdown 文本单元
- **Kernel（内核）**：执行代码的计算引擎，这里使用 Python 内核
- **输出**：代码运行结果直接显示在单元格下方

### 3.2 安装

```bash
# 使用 pip 安装
pip install jupyter

# 或安装 JupyterLab（下一代界面，功能更强）
pip install jupyterlab
```

> 如果使用 Anaconda，Jupyter Notebook 已预装，无需额外安装。

### 3.3 启动

```bash
# 启动经典 Notebook
jupyter notebook

# 启动 JupyterLab（推荐）
jupyter lab
```

启动后，浏览器会自动打开 `http://localhost:8888`。

### 3.4 基本操作

**创建 Notebook：**
- 点击 "New" → "Python 3"（经典版）
- 点击 "+" 图标 → 选择 Python 3 内核（Lab 版）

**常用快捷键（命令模式下，按 Esc 进入）：**

| 快捷键 | 功能 |
|--------|------|
| `A` | 在上方插入单元格 |
| `B` | 在下方插入单元格 |
| `D D` | 删除当前单元格 |
| `M` | 切换为 Markdown 单元 |
| `Y` | 切换为代码单元 |
| `Shift+Enter` | 运行当前单元格并跳到下一个 |
| `Ctrl+Enter` | 运行当前单元格（不跳转） |
| `Alt+Enter` | 运行并在下方插入新单元格 |

**编辑模式（按 Enter 进入）：**
- `Tab`：代码补全
- `Shift+Tab`：查看函数帮助文档

### 3.5 Markdown 单元示例

在 Markdown 单元中可以编写富文本：

```markdown
# 一级标题
## 二级标题

这是**加粗**文本，这是*斜体*文本。

- 列表项1
- 列表项2

| 列1 | 列2 |
|-----|-----|
| 数据1 | 数据2 |

$$ E = mc^2 $$ （LaTeX 公式）
```

### 3.6 魔法命令

Jupyter 提供了一些特殊命令（以 `%` 或 `%%` 开头），提升效率：

```python
# 行魔法（作用于单行）
%timeit sum(range(1000))        # 测试代码执行时间
%pwd                            # 显示当前工作目录
%ls                             # 列出文件
%matplotlib inline              # 图表内嵌显示
%load_ext autoreload
%autoreload 2                   # 自动重新加载修改的模块

# 单元魔法（作用于整个单元格）
%%time                          # 统计整个单元格运行时间
%%bash                          # 在单元格中运行 bash 命令
%%writefile test.py             # 将单元格内容写入文件
```

## 四、Google Colab（可选）

如果不想在本地配置环境，或需要 GPU 加速，可以使用 Google Colab：

- 地址：[https://colab.research.google.com/](https://colab.research.google.com/)
- 完全免费，提供 GPU 加速（需手动开启：代码执行程序 → 更改运行时类型 → GPU）
- 基于 Jupyter 格式，操作方式类似
- 支持直接从 Google Drive 加载数据

> 注意：Colab 服务器在境外，国内访问可能需要特殊网络环境。

## 五、推荐工作流

对于机器学习项目，推荐的工作流程是：

1. **探索阶段**：使用 Jupyter Notebook 进行数据探索、可视化、算法实验
2. **开发阶段**：将稳定的代码整理到 VS Code 中的 `.py` 脚本
3. **项目组织**：
   ```
   my-project/
   ├── data/           # 数据集
   ├── notebooks/      # 实验用 Notebook
   ├── src/            # 源代码
   ├── models/         # 保存的模型
   ├── results/        # 输出结果
   └── requirements.txt # 依赖清单
   ```

## 六、常见问题

**Q：VS Code 中 Python 扩展无法识别解释器？**
A：确认 Python 已正确安装并添加到 PATH；在命令面板中手动选择解释器路径。

**Q：Jupyter Notebook 启动后浏览器没自动打开？**
A：手动复制终端中显示的 URL（含 token）到浏览器地址栏访问。

**Q：Jupyter 中导入库报错但终端中正常？**
A：可能是 Jupyter 使用的内核与终端的 Python 环境不一致。在 Notebook 中运行 `import sys; print(sys.executable)` 查看当前内核路径，确保与目标环境一致。

**Q：如何修改 Jupyter 默认启动目录？**
A：运行 `jupyter notebook --generate-config` 生成配置文件，编辑 `c.NotebookApp.notebook_dir` 设置默认目录。
