# 开发环境

工欲善其事，必先利其器。本部分讲解机器学习专属开发环境的搭建，包括编辑器/IDE 的选择部署，以及 Anaconda 虚拟环境管理，为后续代码编写和项目运行提供稳定支撑。

## 章节列表

- [编程环境部署](编程环境部署.md) — VS Code 与 Jupyter Notebook 的安装配置
- [Anaconda 环境配置](Anaconda环境配置.md) — 虚拟环境创建、库管理、镜像源配置

## 学习目标

完成本部分学习后，你将能够：

1. 选择并搭建适合机器学习的开发环境
2. 熟练使用 VS Code 编写和运行 Python 代码
3. 使用 Jupyter Notebook 进行交互式数据分析
4. 使用 Anaconda 创建和管理独立的虚拟环境
5. 解决多库版本兼容、环境混乱等常见问题
